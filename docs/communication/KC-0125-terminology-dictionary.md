## Avoid in Urdu communication

اپ ڈیٹ، اپ ڈیٹس، اسٹیٹس، ٹاسک، ریمائنڈر، ایکشن، یاددہانی، نرم یاددہانی، رابطہ مکمل، Reminder / Gentle Reminder / Friendly Reminder / Urgent / Immediate Action Required

Also avoid soft-policing phrasing (charter): جب سہولت ہو، جب موقع ملے، اگر ممکن ہو
